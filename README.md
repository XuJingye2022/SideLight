# Sidelight

[![CI](https://github.com/XuJingye2022/SideLight/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/XuJingye2022/SideLight/actions/workflows/ci.yml)

你的写作，AI 在页边。左侧写作，右侧按需补光。

发布目标：面向所有中文写作者的桌面 Markdown 编辑器。现有两套原生宿主：Windows 的 **C# WebView2 宿主**（`host/`）与 macOS 的 **Swift/AppKit/WKWebView 宿主**（`host-mac/`）。逐版本变更见 [docs/CHANGELOG.md](docs/CHANGELOG.md)。下文命令里的 `Ctrl` 在 macOS 上换成 `Cmd`（例如保存是 `Cmd + S`，撤销是 `Cmd + Z`）。

## 下载

最新版本：[github.com/XuJingye2022/SideLight/releases](https://github.com/XuJingye2022/SideLight/releases)。

- **Windows**：`Sidelight-<版本>-win-x64-setup.exe`（per-user 安装包，装到 `%LOCALAPPDATA%\Programs\Sidelight`，卸载保留用户数据）或 `Sidelight-<版本>-win-x64-portable.zip`（免安装）。
- **macOS**：`Sidelight-<版本>-macos-universal.zip`，**Universal（Apple Silicon + Intel）**，要求 macOS 13+；zip 根目录里还有 `README.txt`，一个包两种芯片都能跑。

Windows 首次安装（**先看运行时**）：

- 需要 **Microsoft WebView2 运行时**：Windows 11 自带；没有时安装器会弹提示并**中止安装**（不会装出一个打不开的程序）。先装 <https://go.microsoft.com/fwlink/p/?LinkId=2124703>，再重跑安装器。
- 双击 `Sidelight-<版本>-win-x64-setup.exe`。安装包没有代码签名，SmartScreen 会拦一次：点「更多信息」→「仍要运行」。
- 默认装到 `%LOCALAPPDATA%\Programs\Sidelight`（可改）。从开始菜单启动、卸载在「设置 → 应用」；具体步骤见 [`packaging/README.md`](packaging/README.md)（开始菜单快捷方式与 HKCU 卸载项**尚未人工验**）。卸载保留 `%LOCALAPPDATA%\Sidelight`，要彻底清掉手动删。
- 校验下载：`Get-FileHash -Algorithm SHA256 <文件>`（或 `certutil -hashfile <文件> SHA256`），与 Release 页的 `SHA256SUMS-<版本>.txt` 对照。
- 便携包：解压 `…-win-x64-portable.zip`，双击 `Sidelight.exe`，同样会被 SmartScreen 拦一次。

macOS 首次打开（未签名时按系统版本二选一，**每次更新后重做**）：

- **macOS 15 及更新**：把 App 拖进「应用程序」→ 先双击一次（提示里只有「完成」是正常的）→ 打开「系统设置 → 隐私与安全性」→ 点「仍要打开」→ 再双击 App → 点「打开」。
- **macOS 13–14**：在 Finder 里右键（或按住 Control 点）App → 选「打开」→ 再点「打开」。
- 命令行去隔离（路径含空格要加引号）：`xattr -dr com.apple.quarantine "<App 路径>"`。
- 提示「已损坏，无法打开」时先别重新下载：先核对 SHA256，再执行上面的 `xattr`，仍失败再反馈。
- 校验（macOS）：`shasum -a 256 <zip 文件>`，与 Release 页的 `SHA256SUMS-<版本>.txt` 对照。
- 签名状态见 Release 说明首行：**未签名、未公证**（ad-hoc，需按上面步骤打开）或**已签名并公证**（通常不再需要额外步骤）。
- 从 0.28.1（arm64）升级：直接覆盖安装即可，数据保留；首次打开步骤要重做。0.28.1 及更早的 arm64 包只支持 Apple Silicon；不确定芯片时看「 菜单 → 关于本机 → 芯片」。

## 现在能做什么

- 左侧文件树：打开文件夹、单独打开一个 `.md` 文件。当前文档高亮。第 59 轮起侧栏头可在「树 / 列表」两态间切换：列表态把工作区所有 Markdown 平铺成一行一篇并显示相对路径，当前文件高亮，切回树态保留展开结构（会话内有效、不落盘；列表态用 ↑↓/Home/End 移焦点，一个 Tab 站）。
- 重开恢复：再打开时恢复上次的文件夹、当前文件与批注（IndexedDB 只存句柄；权限需重新授予时退化为「最近打开」，授权后 `Ctrl+S` 原地保存）。恢复出来的文档只切视图不算改动，不会再问「切换文档」（第 45 轮）。
- Typora 式快速键：`Ctrl+K` 链接、`Ctrl+M` 公式、`Ctrl+P` 快速打开、`Ctrl+1–6` 标题、`Ctrl+0` 正文、`Ctrl+/` 源码；表格里 `Tab` 走格、`Ctrl+Enter` 退出表格；列表里 `Tab` / `Shift+Tab` 缩进 / 反缩进；侧栏 `Ctrl+Shift+1` 大纲、`Ctrl+Shift+3` 文件树、`Ctrl+Shift+L` 折叠。第 68 轮起快速打开有焦点困锁：`Tab` 不会跑到遮罩之后、任意时刻 `Esc` 都能关，关闭或选中后焦点回正文（源码态回源码框），输入框有焦点环。第 89 轮起快捷键也可以自己改：设置 → 快捷键里有 8 条（保存、查找、全局搜索、快速打开文件、切换源码 / 编辑、切换预览、新建文档、导出菜单），点键位后按下新组合即改，与保留键冲突时说明理由并保持原键，`Backspace` 回该条默认，「全部恢复默认」一次复位；改键随设置存盘、重启后生效，旧键不再触发。`Ctrl+K` / `Ctrl+H` 这类固定键不参与改键；快捷键一览里写的是默认值，改过的以设置为准。
- 侧栏第二个页签是大纲：按标题层级列出，当前章节高亮，点一下跳过去；有子级的标题前有 ▸/▾ 可折叠，当前节被折叠时高亮最外层的折叠祖先，光标回到被折叠的子节会自动展开（折叠状态只在这次会话里，不存盘）。第 64 轮起长文里当前章节会自动滚进可见区（越界才滚，手滚不被抢）；第 65 轮起大纲是树语义（`role="tree"` + `treeitem` / `aria-level` / `aria-expanded`），键盘按 ↑/↓ 换条、Home/End 到首尾、← 收起或跳父级、→ 展开或进子行、Enter 跳到章节，Tab 进出各一次并停在同一行。
- 目录：正文里单独一行 `[TOC]`，编辑视图会在它下面画出按标题层级缩进的目录，点条目跳到对应标题（第 58 轮）。第 61 轮起标记行默认收起、光标进入才露出（可以直接改或删），只读预览面板里也列出同一份目录、同样可点击跳转；引用块里的标题不算目录项。原文写 `\[TOC\]` 的一律保持字面；保存仍写回单行 `[TOC]`，往返逐字节不变。第 62 轮起软换行段落里夹一行 `[TOC]` 不再把整段当标记（其余文字照常显示），已打开的文档里手打一行 `[TOC]` 也会立刻出目录。第 73 轮起方向键把光标移到标记段紧邻的前一块末尾或后一块开头也算露出，不必把光标放进标记段：`is-revealed` 随选区重算，不再等下一次文档改动。
- 正文编辑：标题、粗斜体、删除线、行内代码、列表、引用、代码块、链接、表格、任务列表（打 `- [ ] ` / `- [x] ` 直接建任务项，保存写回 `- [ ] `，第 44 轮）；设置里可开快捷行内语法 `==高亮==` / `^上标^` / `~下标~`（第 55 轮加入，第 75 轮起默认开、旧存档自动迁移为开；写回逐字节不变）。第 84 轮起手打当场渲染、第 86 轮起粘贴也渲染（代码围栏与行内代码里不转），`\=` 保存后仍是 `\=`（第 83 轮）。任务项的行高与普通列表相同（33.14 px），复选框中心与首行文字中心相差 0.06 px（第 73 轮；改前 50.14 px 与 7.5 px）。开了快捷行内语法后，光标进入 `==高亮==` 或贴住它的两端时露出 `==` 定界符（第 74 轮：伪元素只显示、不占正文，保存仍写回 `==高亮==`）。第 88 轮起手打 `:smile:` 等 20 枚 emoji 短码当场出 emoji（全角 `：` 也认，一步可撤销），代码围栏与行内代码里不转换。代码块右上角显示语言标签（无语言写「纯文本」），点开可切换；保存写回 ` ```js ` / ` ```ts ` 这类信息串，`` ```js `` 往返逐字节不变（第 91 轮）。第 93 轮起先把一对 `==` / `^` / `~` 打好再回头填内容也认：光标离开、回车或失焦时收成高亮 / 上标 / 下标，打字中不动，一次 `Ctrl+Z` 只回字面定界符。
- 智能标点与自动配对：键盘输入时直引号按上下文变弯引号、`--` 变 `—`（紧邻汉字时出 `——`，第 49 轮）、`...` 变 `…`、中文后的半角 `, ; : ? !` 变全角；左括号与开引号补右半边、光标停在里侧，有选区时用配对标点把选区包起来。`don't`、`1990's` 的撇号与 `![图](a.png)` 的图片语法保持原样；代码块与行内代码内不转换；设置里可关（默认开，旧存档读出来也是开）。收益面是西文态 / 半角态与中英混排输入。第 58 轮起链接目标 `](…)` 与行内 HTML 标签属性里的直引号不再被改成弯引号（敲 `[乙](https://example.com "标题")`、`<img src="assets/a.png" width="300">` 都原样）。
- 工具栏：插入表格、代码块、引用、任务列表、分割线、链接；格式按钮与 H1、H2。
- 保真：打开→保存不再把正文、围栏与行内代码里的 `<` `>` `&` 写成实体（`a < b`、`A & B`、`if (a<b)` 逐字节不变，第 41 轮）；讲转义的段落写 `&lt;div&gt;` 仍是字面实体；行首与列表标记后的 `>` 保持实体，重开不会变成引用块。
- 自动保存：切换/关窗确认框与设置面板开着时不写盘，点「取消」或关掉后自动恢复（第 41 轮）。第 63 轮起停笔不再先写一份整篇草稿：2 s 自动保存先写正文，草稿兜底计时器改 2.5 s 并在保存成功时停表，1 MB 文档停笔一次只写一份全文。第 66 轮起源码模式里的改动也参与停笔自动保存与停笔草稿（超过 256 KiB 的文档不再只有内存一份），状态栏在源码态显示「自动保存排队中」；第 68 轮起源码改字后 2 s 内退出只写一次盘（草稿计时器与自动保存不再各写一份全文）。源码态输入法组合（拼音候选未上屏）期间不写盘、不写草稿；此时按 `Ctrl+S` 不保存，只提示「先完成候选字，再保存。」（第 68/69 轮）。窄窗（≤1119 px）里侧栏抽屉开着时，切换/关窗确认框不再被抽屉与背板盖住（第 137 轮，`.overlay` z 序 40 → 46）。
- 视图：专注模式压暗非当前块，打字机模式把光标保持在视口中部，源码模式可编辑原始 Markdown，预览模式只读渲染全文（含 frontmatter、脚注、公式），预览与编辑同一套排版（Source Han Serif 17px/1.95、36rem 限宽、表格边框、引用左边线；第 40 轮）。四种视图互斥，进源码或预览会自动关掉专注与打字机；离开源码时先把源码写回正文，不会丢字。进源码时光标按正文光标的位置比例落位，长文里第一次击键不会插到文首；关查找框不挪光标。`Ctrl+滚轮` 整页缩放 50–200%（`Ctrl+=` 仍是正文字号，两者分层，第 51 轮），状态栏在 ≠100% 时显示「缩放 N%」、点一下回 100%，130% 起顶栏与工具栏不再出屏（第 54 轮）；`F11` 进出全屏（第 52 轮，宿主窗口内未验）。第 64 轮起源码模式不再卸载编辑器（编辑块隐藏成 0 尺寸）：1 MB 文档进出源码从 9.8 s / 2.1 s 降到 1.2 s / 0.3 s，进出保留阅读位置，预览仍是 `pmCount=0`。第 67 轮起源码里改过字再退出时先显示「正在应用源码改动…」遮罩，再整篇重解析：1 MB 文档点击到遮罩上屏 101–107 ms，4.1 s 长任务排在遮罩之后，总 4.44–4.55 s；退出源码时若输入法还在组合，先等一次 `compositionend`（≤300 ms）再读现值，候选字确实丢了才拦退并提示「先完成候选字，再退出。」（第 69 轮）。
- 点页边任一批注会选中正文里对应的句子并滚到眼前；点正文里的链接会贴着元素弹出编辑框。
- 公式：打 `$x^2$` 得到行内公式；空行打 `$$` 再回车得到块级公式。点公式就地编辑（第 90/91 轮，不再弹浮层）：行内公式当场变成 `$…$` 输入框，改完按 `Enter` 或点别处即回渲染，`Esc` 取消；行间公式在块内直接改 TeX，下面实时显示 KaTeX 预览，`Ctrl+S` 或失焦提交、`Esc` 还原，块首行 `↑` / 末行 `↓` 把光标送出块。`Ctrl+M` 与工具栏「公式」走同一路径。第 73 轮起也可以用键盘：把选区移到行内公式（`Shift+→`）或按方向键选中块级公式时，成品暂时换成 `$…$` / `$$…$$` 源码，移开即恢复，保存字节不变。第 93 轮起先打一对 `$` 再回头填内容也认（`$$` → ← → `E=mc^2` → → 收成行内公式；整段 `$$x$$` 收成块级公式）：光标离开、回车或失焦才收，打字中不动，一次 `Ctrl+Z` 只回字面定界符。
- 底部状态栏：字数、预计阅读时间、选中时的「选区 N 字」（折叠选区即消失），以及当前开了哪些视图模式。
- 拖选一段，点选区旁浮出的「分析」或按 `Ctrl + Enter`。AI 的批注落到页边，正文出现对应高亮。
- 批注分两型：**修订**带改写文字，可逐条「采纳」；**评价**只给判断，只有「知道了」。第 86 轮起批注卡可 `Tab` 聚焦（`role="group"` + `aria-label` 读出「第 N 处 + 引文」），卡片上按 `Enter` 选中正文对应句子并滚到眼前；焦点在卡内按钮上按 `Enter` 仍只触发那个按钮。
- 选区超过约 1500 字时切段、逐段分析；段落本身超长时在段落内部按句子再切。长文的批注能覆盖整个选区，不会只出现在开头。
- 每条批注可以「追问」：就地展开对话，模型带着原文、批注与上下文回答，线程跟着批注存进 `.sidelight`。
- 每条批注可以「联网核对」：用配置好的搜索服务查一次，把带链接的出处列在卡片里。搜索服务可选 Tavily、博查或 DeepSeek 搜索（DeepSeek 的 Key 可与模型 Key 相同），用户自带 Key，搜索服务默认关闭。第 138 轮起核对默认自动：配了搜索服务时，分析一结束就按卡片自行核对出处（同时最多 2 条，不阻塞正文），卡片先显示「核对中…」再列出出处；成功后卡片不再留「联网核对」按钮，失败或没搜到才留「重新核对」。没配搜索服务时跳过自动核对，卡片上仍是置灰的「联网核对」。
- 带 YAML frontmatter 的文档：元数据单独保存，拼回时逐字节一致；状态栏会标「元数据」。
- 脚注：定义块单独保存，行内 `[^1]` 引用会还原文稿里的写法，往返逐字节一致。
- 图片：工具栏「插入 → 图片」，也支持拖入与粘贴；有文件夹句柄时写进 `assets/` 并写相对路径。打开文件夹后，相对路径图片在编辑视图与预览面板里正常显示：同目录、向下相对路径、`../`（笔记放子目录、图放仓库根）与 `%20`（文件名带空格）都支持，Markdown 里仍是 `assets/…`（第 38 轮；第 39 轮补 `../` 与 `%20` 并加占位）。打开文件夹后解析不到的图不再静默破图，显示虚线占位与「图片未找到」提示；浏览器里单文件打开（无目录句柄）与 HTML 导出仍显示不了；桌面宿主双击打开的单篇文档第 57 轮起能显示同目录相对图片（宿主新增 `/__asset`，只回 png/jpg/jpeg/webp/gif/bmp，绝对路径、`..` 与反斜杠一律 403，不加 CORS 头）。第 87 轮起图片可以调宽度：点图片出现右下角手柄，拖动即改（限 40–2000 px），双击手柄复原；改过宽度的图保存成整行 `<img src="…" alt="…" width="N">`，重开宽度不变、再保存逐字节稳定，没改过宽度的图仍写 `![](…)`，列表与引用里的行首前缀保留。
- 查找替换：`Ctrl + F` 打开，命中全部高亮；`Enter` 下一处，`Shift + Enter` 上一处；可单条或全部替换。源码模式下不提供查找定位与替换：查找条会说明原因并把按钮置灰，不再假装替换成功（第 39 轮），要替换先按 `Ctrl + /` 切回富文本。预览（只读）视图里同样整体锁住（第 42 轮，与源码模式同一语义）：要替换先按 `Ctrl + Shift + P` 切回编辑。查找条上有 `Aa`（区分大小写）与 `ab`（整词）两个开关，按下态可切换（第 41 轮；只在会话内有效、不落盘；整词只认 ASCII 词边界，中文按原样匹配）。第 85 轮起单条替换与「全部替换」都会提示「替换了 N 处」，0 命中提示「没有可替换的匹配」。
- 全局搜索：`Ctrl+Shift+F` 搜整个工作区的 Markdown（对话框按需加载，不进首屏），结果显示「相对路径:行号」与命中片段，点一条直接打开那个文件并把词回填进查找条（第 59 轮）。一次最多列 200 条命中；读不到或超过 1 MiB 的文件跳过，提示里会说明跳过了几个（第 60 轮）。点中当前文档的命中不再整篇重载，滚动位置、未保存改动与撤销历史都保留（第 60 轮）。一个 `Esc` 关对话框并把焦点送回正文；没有打开文件夹时提示「先打开文件夹」。
- 粘贴：`Ctrl+V` 保留格式，`Ctrl+Shift+V` 粘贴为纯文本（浏览器原生键，桌面宿主未验证）。第 92 轮起剪贴板里是纯文本 Markdown（标题、列表、引用、围栏、表格、粗体、链接、行内代码、`$…$` 公式）时直接按格式落进正文，一次 `Ctrl+Z` 撤回；剪贴板带图片、真富文本（HTML 里有结构）或超过 200,000 字符时仍走原来的粘贴路径；代码块与行内代码里粘贴保持字面，表格单元格里只收行内内容。

## 现在不能做什么

- 文件树只能删文件：不能移动、复制文件，也不能删目录；重命名只支持同目录 `.md`/`.markdown`（目标已存在会拒绝）。没有应用内「恢复」或 trash 浏览界面，恢复要在资源管理器里把文件挪回去。trash 只增不减，不自动清理，卸载也不删。
- 修订快照只在「在审」面板里按保存时刻列出最近 8 份的字节数与批注数（每次保存写一份快照，同一正文不重复写）：快照只记批注与字节数，不存正文，不能回到旧版正文。
- 可访问性还有 P2 延后项：骨架的 `role="dialog"`/`aria-busy`、正文开头 Tab 回环删除，本轮不做。已补：批注卡可聚焦并按 `Enter` 跳句（第 86 轮）、设置主题组可用方向键且初始焦点落在选中项（第 77/82 轮）、字数明细面板按 `Tab` 会关面板并把焦点送回触发钮（第 77 轮）、斜体 `I` 与状态栏字数钮撑到 24×24（第 82 轮）。性能侧延后：memo 化、B4/B5、2 MB 读取进度条。1 MB 多节点文档载入 112 s → 2.9 s（第 52 轮，100 KB 1.1 s）；逐键已从 p50 126 / p95 149 ms 降到 100 KB p50 38 / p95 39、1 MB p50 148 / p95 159 ms（第 56 轮，只记基线、不设绝对门槛）；1 MB 切源码第 64 轮起不再卸载编辑器，进 p50 约 1.2 s、退约 0.3 s（门槛进 ≤1,500 / 退 ≤600 ms，第 67–69 轮回核 1,156–1,227 / 294–310 ms），进态仍有约 1.2 s 的整块等待；源码里改过字再退出要整篇重解析，1 MB 档总 4.4–4.5 s（第 67 轮起有遮罩，长任务仍占这段时间，B-144 门槛 ≤5,330 ms）；1 MB 停在源码态时第 81 轮起逐键不再对全篇重算字数（每键 longTask p50 85 → 56 ms，状态栏字数 300 ms 后更新）。窄窗设置面板第 80 轮起分节折叠，1000×620 的内容溢出 432 → 62 px。
- 键盘与查找的四条边界（第 43 轮补第四条）：预览（只读）里查找条整体锁住，命中计数不再显示、上一处/下一处不可用（与源码模式一致）；预览与源码里工具条格式、插入命令与表格条都不可用（第 43 轮，与查找替换同一条只读口径），要改正文先按 `Ctrl+Shift+P` / `Ctrl+/` 回编辑；页边批注卡片可以 `Tab` 到（第 86 轮，卡片上 `Enter` 跳句）；表格工具条的贴靠位置（离表格 742 px）与行列拖拽重排仍未支持。窄窗抽屉开着时确认框已盖在抽屉之上（第 137 轮），但 `Esc` 次序仍是先关抽屉、后关确认框（既有行为，本轮未改）。
- 还没有自动更新。Windows 包没有代码签名，SmartScreen 会拦一次；macOS 默认 ad-hoc（未签名、未公证），配了 Apple secrets 的流水线才会签名 + 公证。装完的 HKCU 卸载项、开始菜单快捷方式、默认安装路径、真人双击与 SmartScreen，以及勾选关联后「打开方式」是否出现、卸载是否残留，尚未人工验。Windows 安装包从 [Releases 页](https://github.com/XuJingye2022/SideLight/releases)下载（per-user，装到 `%LOCALAPPDATA%\\Programs\\Sidelight`，卸载保留用户数据），步骤见 [`packaging/README.md`](packaging/README.md)；也提供便携 zip。
- `.md` 默认不关联。安装时勾选「在「打开方式」中加入 Sidelight」后，右键 `.md` 的「打开方式」里会多一项；默认程序仍要在 Windows 设置里自己选，安装器不改它。
- 密钥存在浏览器 localStorage，没有加密，也没有系统钥匙串。
- 表格：没动过的表格整块写回原文（表内字节与 02 型单空行）；改过单元格、增删行列或改对齐的表格会重新排版，且不弹保存确认；表格前后 ≥2 空行会规范化成一个。引用式链接定义块默认源码打开，写回原文；切回富文本首次保存仍拦一次。列宽不写进 Markdown，重开按内容重新均分。
- 行内 HTML 除四个白名单标签外只保真不渲染：正文里看到的是 `<kbd class="x">` 这类文字，不是键盘样式（白名单 `<kbd>` / `<mark>` / `<sub>` / `<sup>` 例外，见上）。保真的边界（第 41 轮实测）：4 空格缩进代码块里的 `<` 保存后仍是 `&lt;`；「缩进 ≥4 的 ``` + 紧跟裸 HTML 行」的混写文档会把裸 HTML 当块、标签丢；同一篇里既写字面实体（`&lt;`）又写裸 `&` 时那一类实体整篇保持。`&#8212;` 这类**数字实体**在打开时会被解码成字符，重新保存字节会变（渲染不变，第 49 轮）。
- 图片在没打开文件夹时只能内联，不进 `assets/`；浏览器里单文件打开（无目录句柄）时相对路径图片仍显示不了（桌面宿主双击单篇第 57 轮起例外，见上）。调过的宽度只作用于编辑视图：HTML 导出与只读预览不写宽高属性（第 87 轮）；顶层 1–3 空格缩进的规范形行保存时会去缩进。
- Mermaid 图只在编辑视图里画：预览面板与 HTML 导出仍显示围栏原文；同一文档里两段相同的代码各渲染一次。字号只能调大小，不能换字体。
- 目录在编辑视图、只读预览与 HTML 导出里都有（第 76/79 轮起导出带同一份目录与锚点）；源码模式不显示，打印仍未单独验。目录默认收起标记行，光标停在标记行或紧邻的前后块时才露出。
- 露出源码只是装饰，不能直接在成品上编辑：`==` 的定界符与公式的 `$…$` / `$$…$$` 由伪元素画出，正文里没有那份文字；公式是 atom 节点（`contenteditable=false`），纯 `→` 会跳过它，要 `Shift+→` 拉出选区、或对块级公式按 `↑`/`↓` 成节点选区才露出。要改公式仍按上一节的就地编辑（点它）或 `Ctrl+M`（第 73/74 轮）。
- 先打定界符再填内容的四个出口边界（第 93 轮）：只在光标离开、回车、失焦时收；点远处的段落或按 `End` 到行尾不算「离开」（只有失焦兜底）；多行 `$$\n…\n$$` 跨段不自动收；表格单元格里的块级公式只走了代码路径，未在真机验；粘贴与拖入落下的字面定界符不转，已载入文档里的字面 `$x$` 与 `==…==` 也不转。
- 编辑器内复制再粘贴会丢三枚快捷行内语法的样式：含 `==高亮==` / `^上标^` / `~下标~` 的段落用 `Ctrl+C` / `Ctrl+V` 粘回时样式消失（字不丢；这三枚 mark 的 `parseHTML` 返回空表，第 92 轮实测）。纯文本 Markdown 粘贴（第 92 轮）不受影响。
- 粘贴解析的边界（第 92 轮）：剪贴板里 `text/html` 真带结构（如 `<b>`）时不按 Markdown 解析，交回浏览器 / 宿主默认粘贴；带属性的 `<span>` 与编辑器内部复制的 `data-pm-slice` 同样不接管；转义写法 `\$x\$` 不按公式解析。
- 自动联网核对的两条边界（第 138 轮）：同一批内容重跑分析时卡片沿用已有出处（`replaceInWindow` 按既有设计保留 `sources`），自动核对仍会再搜一次——这次若失败，失败态被旧出处挡住，只弹一条提示、不出现「重新核对」；分析被中止时不触发自动核对（只有静态核对，未在真机构造中止）。
- 全局搜索一次最多列 200 条命中，读不到或超过 1 MiB 的文件跳过（提示里说明跳过了几个）；只搜 Markdown，没有跨文件替换；源码 / 预览只读模式下查找条是锁住的，点结果只在编辑视图里回填。文件列表态没有右键菜单，删除与重命名仍只在树态。
- 智能标点的已知限制：中文后的 `.` 不转 `。`；反引号不配对（保住 `` `a` `` → 行内代码）；没有成对退格（空配对 `()` 要按两次退格）；中文后的 `!` 紧跟 `[` 时不转（保住 `![图](a.png)`）；空段落（或首尾没有紧邻汉字）打 `--` 仍是一个 `—`，这是为保住 `---` + 空格出分隔线；中文句子里（紧邻汉字）打 `--` 直接得 `——`，`甲 -- 乙` 这类用空格隔开的仍是 `甲 — 乙`（第 49 轮）；含 `|` 的行不把 `--` 换成 `—`（保住手打的表格分隔行）。真实中文输入法在中文态是否本来就上屏全角、智能标点在组合输入上屏那一次会不会重复转换，都没验。
- 真模型没测过：没有 key。中文输入法（组合输入、候选窗、组合期间开对话框）在浏览器与宿主里都没验。源码态的组合与退出只在 CDP `imeSetComposition` 下验过：合成组合 blur 提交的是原始串（`zhong`），不等于真输入法的候选字上屏时序，WebView2 宿主内同一条路径也未验（第 68/69 轮）。关窗只在自动化里验过：真实 Alt+F4、注销/关机、真实 IME 组合输入下的关窗，以及草稿写失败（只读目录）的可见错误，都没人工验。
- 写回只在 UTF-8 / UTF-16LE / GBK 与 **5.5 MiB（5,767,168 B）** 以内文件上验过；超过上限的提示写清「仍在『哪一篇』」，正文保留上一篇（不清空）。已验边界：**5.2 MiB 可打开、6.1 MiB 拒绝**；5.5–6 MB 之间未验。文件被占用、网络盘、中文长路径、真人双击下的保存对话框与写回都没验。

- 「清除」立即清空列表（可撤销一次）；`recent.json` 删掉，但日志与草稿不受影响。
- 日志在 Windows **安装目录**：`host.log` 只记 basename，超过 1 MB 轮转为 `host.log.1`；例外是 `navigate`/`permission` 会记**导航的完整 URL** 与权限请求 URI。删除 `host.log*` 可清；macOS 宿主不落盘日志。
- 草稿与批注在文档同目录 `.sidelight/`：草稿 `drafts/`，批注 `annotations/`；只在本机，不发网络。
- trash 只在本机：删除的文件进工作区 `.sidelight/trash/`，不发网络、不自动清理、卸载不删；要彻底清掉，手动删这个目录。
- Windows 卸载保留 `%LOCALAPPDATA%\Sidelight`（`recent.json` 与 `%LOCALAPPDATA%\Sidelight\WebView2` 配置）；要彻底清掉，卸载后手动删。
- macOS 的最近记录在 `~/Library/Application Support/Sidelight`；WebView 存储由 WebKit 决定，位置**未核实**；文档同目录 `.sidelight/`（草稿、批注、trash）与 Windows 一致。
- 换包/升级不丢数据；同一时间只保留一个 `Sidelight.app`；不要改 `CFBundleIdentifier`（改了会当成另一个应用，数据与 Gatekeeper 记录都会分叉）。
- File 菜单有打开/打开最近/关闭窗口；Edit 菜单有撤销/重做/剪切/拷贝/粘贴/全选，快捷键交给系统（macOS 用 `Cmd`）。
- 无遥测，启动不联网；联网只发生在用户触发 AI 分析（模型请求）、分析结束后的自动出处核对（配了搜索服务时）或手点「联网核对」时。

## 已定的技术决策

- 编辑器内核：Tiptap 3.34（ProseMirror），文档树是真相。见 [ADR 0001](docs/adr/0001-document-tree-is-the-truth.md)。
- AI 接入：用户自带密钥，协议锁 OpenAI 兼容。见 [ADR 0002](docs/adr/0002-ai-access-byo-key.md)。
- 意见形式：页边批注，锚定正文范围，修订逐条采纳。见 [ADR 0003](docs/adr/0003-margin-annotations.md)。
- 上下文：选区 + 前后各一段，上限 1500 字；没选区时取光标所在段落。
- AI 不直接写正文：每次写入都要人点一次「采纳」。
- 桌面壳：C#/.NET Framework + WebView2 宿主，零管理员；Tauri 2 只在拿到管理员/MSVC 或改由 CI 出包时重评估。见 [ADR 0004](docs/adr/0004-webview2-host-before-admin.md)。
- 宿主 origin：固定回环 `http://127.0.0.1:47821`，端口被占就报错退出，不换端口。见 [ADR 0005](docs/adr/0005-loopback-fixed-origin.md)。
- 写回：宿主是唯一写者，页面从 `/__doc` 拿正文与编码元数据、拿不到路径；保存走 `postMessage`，宿主用同目录临时文件 + 原子替换。见 [ADR 0006](docs/adr/0006-argv-writeback.md)。
- `.md` 关联：只加「打开方式」候选，opt-in、默认不勾、不改默认程序，只写 HKCU。见 [ADR 0007](docs/adr/0007-markdown-association.md)。
- 宿主草稿：`draft-save` 写文档同目录 `.sidelight/drafts/`，关窗问「取消 / 存草稿 / 丢弃」。见 [ADR 0008](docs/adr/0008-host-draft-and-close-guard.md)。
- 最近打开：宿主记 8 篇，`/__recent` 只回哈希 id；日志只记 basename。见 [ADR 0009](docs/adr/0009-recent-files.md)。
- 表格：签名未变的表格整块写回原文，改过的表格按编辑器规范排版。见 [ADR 0010](docs/adr/0010-table-block-reuse.md)。
- 引用式链接：含定义块的文档载入后默认源码模式，切回富文本首次保存仍拦一次。见 [ADR 0011](docs/adr/0011-source-mode-for-reference-links.md)。
- KaTeX 惰性加载：首屏不再含 KaTeX，首次渲染公式时才加载。见 [ADR 0012](docs/adr/0012-katex-lazy-loading.md)。
- 文件树只做删除：移到工作区 `.sidelight/trash/`，不提供应用内恢复，不自动清理。见 [ADR 0013](docs/adr/0013-file-tree-operations.md)。
- 文件重命名：同目录、只接受 `.md`/`.markdown`、目标存在拒绝、`move()` 唯一路径、缓存写新成功才删旧。见 [ADR 0014](docs/adr/0014-file-rename.md)。
- macOS 打包：默认 Universal（arm64 + x86_64），签名/公证可选三态，zip 内带 README。见 [ADR 0015](docs/adr/0015-macos-universal-and-signing.md)。
- 会话恢复：IndexedDB 只存句柄、权限三态、失败退化；宿主 `/__annotations` 端点。见 [ADR 0016](docs/adr/0016-session-restore.md)。
- Mermaid：**第 36 轮实现**（产品负责人 2026-11-17 批准；安装包预算已放宽到内部 45,000,000 / 硬线 50,000,000），惰性方案与体积实测见 [ADR 0017](docs/adr/0017-mermaid-lazy-loading.md)。

## 已知的重要问题：Markdown 往返损失

`npm run roundtrip` 把 9 个真实样本读进编辑器内核再写回，逐行对比。三条路径分开报：富文本 **7 / 9** 完全保真、源码路径 **9 / 9** 等值（未编辑）、富文本首次保存仍拦截 **1 / 9**（04 引用式链接）。逐样本表见 [docs/roundtrip-report.md](docs/roundtrip-report.md)。

frontmatter、脚注定义、行内 HTML 与公式逐字节保真。表格只在「没动过」时整块写回原文；引用式链接定义块默认源码打开。差异见 [docs/roundtrip-report.md](docs/roundtrip-report.md)。
