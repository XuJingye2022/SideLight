# Sidelight 设计语言

日期：2026-11-21（第 143 轮）。来源：用户 2026-11-21 反馈「无用 UI 多、要精简，参考 Typora」与第 142 轮常驻控件盘点（`docs/iteration/round-142/ui-inventory.md`）。参照物：Typora 主窗口（`shots/typora/02-window-maximized.png`）——7 项菜单栏、状态栏 3 项、无常驻命令按钮。

一句话：**正文优先，控件按需；一个动作一个常驻入口，删掉的入口必须有菜单或键位等价物。**

## 1. 八条原则

1. **内容优先**：一行顶栏 + 正文 + 一行状态栏，正文 36rem 居中。不做第二行常驻工具栏。
2. **无常驻格式工具栏**：格式靠快捷键、菜单与就地交互（点计算公式、点链接、浮动「分析」）。唯一保留的块级入口是「插入 ▾」——表格与图片没有键位。
3. **单入口**：一个动作只留一个常驻入口。第二入口只能进菜单或键位（例：「保存」只在顶栏留一个按钮，菜单与 `Ctrl+S` 是第二、第三入口）。
4. **侧栏按需**：左右栏都可收起；键位唤出（`Ctrl+Shift+1/3/L`）。右栏窄窗是抽屉，宽窗是贴右缘的 280–520 px 网格轨；展开态只记在会话里。
5. **状态栏只报写作事实**：字数（含选区）、保存、错误与撤销、缩放。不重复视图模式，也不重复文件名。
6. **顶栏控件不随视图变**：批注钮常驻，非编辑视图 `disabled`（`src/App.tsx:5867`）；「对比」「批注」不再按 `viewMode` 条件渲染，顶栏宽度不跳。
7. **菜单只用四组：文件 / 插入 / 视图 / 帮助**：顶栏只露「文件 ▾」「插入 ▾」两个触发器（`src/App.tsx:5702`、`:5756`），导出 / 视图 / 帮助三组并进文件菜单（`src/components/FileMenu.tsx:225` / `:245` / `:269`）；不引入 Typora 那样 7 项原生菜单栏，也不设「段落 / 格式」组——H1–H6 只有键位（`Ctrl+1–6` / `Ctrl+0`）。
8. **不砍功能**：进菜单或键位即算保留；每个删除项都要在下面「等价入口表」写清去处，行数 = 实际删除的常驻控件数。

## 2. 界面骨架

```text
┌ 顶栏 ─ 品牌 · 文件▾ · 文档名+脏点 · 分析 · 保存 · 插入▾ · 批注 ─┐
│ 正文（36rem 居中）                                              │ 右栏（按需）
│                                                                  │ 对话/批注页签 + 状态 + 在审 + 收起
└ 状态栏 ─ 字数·选区 / 自动保存 / 草稿恢复 / 删除撤销 / 缩放 ─────┘
```

文件菜单四组：文件（新建、另存为、打开文件、打开文件夹、查找替换）→ 导出（HTML、Markdown、纯文本、打印·PDF）→ 视图（对比、专注、打字机、源码、预览，`role="menuitemradio"` + `aria-checked`）→ 帮助（快捷键一览、设置…）。最近打开接在帮助之后，整段可缺省。

## 5. 判据与验证

- **新增常驻控件必须同时删一个，或进菜单/键位**；否则不加。这条是体验阈值，不是体积门：第 144 轮起**首屏体积只记录、不阻塞**（用户 2026-11-21 取消首屏硬线），`npm run verify` 只报字节（第 143 轮实测真实首载 321,273 B），加静态代码不再需要先算体积。
- 菜单项用写作语汇、键位写右侧；动作后焦点按动作归还（新建回正文，其余回「文件」触发器）。
- 实测：`scripts/keyboard-acceptance.mjs` **52/52**（含 `Ctrl+Alt+E` 打开菜单并聚焦导出首项、`?` 仍能开一览）；`.tmp/e2e-r143-ui.mjs` **23/23**（含文件菜单 5 个 radio 与 `aria-checked`、文件→帮助→设置、`F8` 后 `.is-dimmed` ≥1、状态栏文案、右栏 1440/1024 两态、首卡上移 31 px（tester 另一夹具实测 −36 px，门槛 ≥20 成立））；`.tmp/e2e-r140-b.mjs` 38/38；`npm test` **72 文件 1003 条 0 fail**；`npm run verify` 真实首载 321,273 B。
- 未验：`F8` 在 WebView2 宿主里会被宿主吞掉（真宿主未跑；菜单项是等价入口）；真实中文 IME；macOS 宿主。
