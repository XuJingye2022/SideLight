# 第 21 轮简报（深水区侦察，6 路）

## 上轮结果

- v0.30.3：Windows 安装包/便携包 + macOS Universal 已发布；CI 三组必过。
- 首屏 284,766 B；测试 16 文件 205 条；20 轮计划/验收归档在 `docs/iteration/`。
- 已知未验：macOS 真机、签名/公证、Intel 运行、100 KB/1 MB 逐键性能、真实 IME、HKCU/双击/SmartScreen。

## 本轮目标

前 20 轮已扫掉明显问题。本轮起每轮 6 名侦察，分头盯不同子系统，找**深水区缺陷**与**能明显改善写作体验的改动**。

1. **编辑器内核**：Markdown 保真、撤销/重做、粘贴/拖放、表格、脚注、公式、frontmatter、HTML/callout、源码/富文本切换。
2. **数据与恢复**：保存/自动保存/草稿/最近/重命名/删除/宿主写回/崩溃恢复/多窗口/大文档。
3. **首次使用与可发现性**：首屏、空态、设置、菜单、快捷键、错误文案、引导。
4. **长文工作流**：大纲、页边批注、专注/打字机、查找、导出/打印、阅读。
5. **安装与平台**：Windows 安装/卸载/关联/SmartScreen、macOS 包/Gatekeeper/签名、自动更新缺失。
6. **性能与离线**：启动、100 KB/1 MB 输入与滚动、内存、离线、chunk/首屏预算。

## 三个交付要求

- 每条发现必须有**可复现证据**（步骤/选择器/数字/截图/日志），不许只写“建议优化”。
- 只报**新问题**，不复述 STATE/CHANGELOG 已记录的未验项；已知项只在新证据推翻时重报。
- 每条给：影响（用户能否感知/是否丢数据）、修复成本（S/M/L）、建议改法。
