## F1 常驻 44 个控件，Typora 是 3 个

顶栏 8 + 格式栏 11 + 左栏 9 + 右栏 6 + 状态栏 10 = **44**，另有每行「⋯」与 11 类对话框。
Typora（`shots/typora/02-window-maximized.png`）：7 个菜单 + 状态栏 3 项（左两图标、右 186 词），**无常驻命令按钮**。

重复 5 组：

1. 状态栏 4 个模式 chip ≡ 工具栏 `is-on`（`StatusBar.tsx:109-112`；工具栏常驻，`styles.css:2474` 只压暗段落）。
2. 左栏「⟳」≡「⋯ → 刷新」（`FileTree.tsx:479-488`、`TreeActions.tsx:239-249`）。
3. 「关闭文档」≡「新建」（都接 `newDocument`，`FileMenu.tsx:25-26`、`App.tsx:5696-5697`）。
4. 隐藏右栏两条常驻路：顶栏「批注」+ 栏头 ×/▸（`App.tsx:5843-5860`、`MarginRail.tsx:341-373`）。
5. 「保存到 X」≡ 顶栏文档名；「选区 N 字」「元数据」≡ 字数明细入口。

## F2 设计语言草案

来源：`docs/iteration/typora-features.md:43,53`、`:123`（**不引入原生 7 菜单栏**，既有决定）与上述截图。

1. **内容优先**：一行 chrome + 正文 + 一行状态栏；正文 36rem 居中。
2. **无常驻格式工具栏**：格式靠快捷键、菜单、就地交互。只留「插入」，因为表格与图片没有键位。
3. **单入口**：一个动作一个常驻入口；第二入口只能进菜单或键位。
4. **侧栏按需**：可收起，键位唤出（`Ctrl+Shift+1/3/L` 已有），展开态会话内保留。
5. **状态栏只报写作事实**：字数、保存、错误与撤销；不重复模式与文件名。
6. **稳定位置**：顶栏控件集合不随视图变（现在「对比」「批注」只在编辑视图渲染，宽度会跳）。
7. **菜单用写作语汇**（文件/编辑/段落/格式/视图/帮助），键位写右侧。
8. **不砍功能**：进菜单或键位即算保留，删除项必须逐条写等价入口。

## F4 风险

1. **体积**：真实首载 321,950 / 硬线 325,000（余 3,050）。删控件减字节，新增菜单组与文案会加。第 143 轮**先删后加**，每步跑 `npm run verify`。
2. **键位缺口（硬阻塞）**：专注/打字机无键位（`ShortcutsDialog.tsx` 无 F8/F9）。删钮前先补键位或留菜单项，否则不可达。F8/F9 在 WebView2 是否被吞未验。
3. **可发现性**：删 B/I/S 后新手无视觉入口，与 Typora 同款取舍；不加引导浮层（体积）。
4. **既有测试按 DOM 断言**：删钮会让 `keyboard-acceptance`、round-140 E2E、`railDiffA11y` 红。删前 grep，脚本与产品同批改。
5. **保存信任**：用户刚遇保存失败，本轮不动「保存」按钮与提示形态。
6. **右栏压头部**：不丢 `tablist`、roving tabindex、`aria-controls`（B-221）；8 px 拖宽把手别压进不可见区。

UNVERIFIED：新布局未在 1024×700 抽屉态、130% 缩放实测（B-014 边界）；F8/F9 真宿主未验。
