## 本轮目标

1. **视觉一致性**：字号/行高/间距/圆角/边框/阴影收敛到 token；浅色与深色都不漏色；焦点环清楚。
2. **可访问性**：正文与控件对比度达 WCAG AA；键盘焦点可见；`prefers-reduced-motion`；图标按钮有可读名称。
3. **空态与细节**：文件树/大纲/最近/批注的空态文案与留白一致；窄窗 1024 不溢出。
4. 不做大改版，不动编辑器内核；首屏仍 ≤285,000；版本 0.30.0。

## 三个视角

- **体验**：浅/深/跟随系统三档，1440/1280/1024 截图；字号层级、留白、按钮/菜单/弹窗一致性；空态与加载态。
- **缺陷**：深色模式漏白/漏黑、硬编码颜色、焦点环被 `outline:none` 抹掉、对比度不足、`prefers-reduced-motion` 缺失、键盘可达性回退。
- **发布**：WCAG 2.1 AA 关键项；axe 类静态检查；截图与 README 是否需要更新；新增 CSS 字节对首屏的影响。
