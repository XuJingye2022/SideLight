# 批注落在页边，修订逐条采纳

长文里，右侧一整列的卡片看不出「要改哪里」。改成老师批改论文的形式：AI 的意见锚定到正文的具体范围，页边一条一条对着句子放。修订类意见带改写文字，人点「采纳」才写进正文；评价类没有采纳按钮，只有「知道了」。

考虑过的替代方案是继续用右侧列表、点击时滚动定位。它省事，但读者仍要在列表和正文之间来回跳，而且一条针对短语的意见指不出是哪个短语。

代价是锚定的脆弱：批注记的是文档位置，正文一动就要修正。当前做法是每采纳一条就按长度差平移其余批注，被替换范围覆盖的批注直接丢弃。跨段大改会让批注漂移，这一条还没解决。

它同时改写了早期的「AI 只读」约定：AI 仍然不直接改写，但采纳后的文字由 AI 提供。区别在于每一次写入都要人点一次。
