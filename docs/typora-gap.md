# Typora 差距表

对照 [Typora 官方文档](https://support.typora.io/Markdown-Reference/)（2026-11-15 查）逐项核对。左列是 Typora 的能力，中列是 Sidelight 现状。

优先级：**P0** 写作必需或涉及数据安全，**P1** 接近 Typora 的体验，**P2** 可以晚做。

## 已经有的（28）

| 能力 | 现状 |
| :--- | :--- |
| 标题、强调、列表、引用、代码块、表格、链接、分割线 | 有，编辑即时渲染 |
| 任务列表 | 有 |
| 大纲面板 | 有，当前章节高亮，点击跳转 |
| 源码模式 | 有，可编辑，与编辑模式互切 |
| 专注模式、打字机模式 | 有 |
| 文件树与单文件打开 | 有；打开文件夹、单独开一个文件、示例工作区 |
| 字数与阅读时间 | 有，底部状态栏 |
| 撤销重做 | 有快捷键，没有按钮 |
| 保存（Ctrl+S） | 有 |
| 页边批注与逐条采纳 | 有，Typora 没有 |
| YAML frontmatter | 有，单独保存不进编辑器，拼回时逐字节一致 |
| 保存前格式对比 | 有，Typora 没有；保存前把被规范化的行列给你看 |
| 图片拖入与粘贴 | 有；有文件夹句柄时写进 `assets/` 并写相对路径 |
| 查找与替换 | 有；Ctrl+F 打开，命中全部高亮，可单条或全部替换 |
| 字号缩放 | 有；设置里调 12–26，`Ctrl+=` / `Ctrl+-` 调大小，`Ctrl+Alt+0` 复位（`Ctrl+0` 是正文样式，不是复位，见 `README.md:54`） |
| 脚注 | 有；定义块单独保存，行内引用还原，往返逐字节一致 |
| 自动配对括号与引号 | 有；键盘输入时生效，设置里可关（`src/lib/smartTyping.ts`） |
| 智能标点 | 有；直引号转弯引号、`--` 转破折号、`...` 转省略号，设置里可关 |
| 缩进与反缩进 | 有；列表内 Tab / Shift+Tab，表格内 Tab 走格，正文 Tab 插 2 空格 |
| 导出 | 有；HTML（样式内联）、Markdown、纯文本、打印 |
| 表格行列 | 有；光标在表格里时出现工具条，可增删行列与整表；表头边界可拖拽改列宽（第 37 轮）；键盘 Tab 走格、Ctrl+Enter 加行、Ctrl+L 删行 |
| 数学公式 | 有；行内与块级，KaTeX 渲染，费用符号不误判 |
| 自动保存与草稿恢复 | 有；每次改动写本地草稿，重启恢复正文、文件名与元数据 |
| Mermaid 图表 | 有；第 36 轮起 ```` ```mermaid ```` 围栏惰性渲染（首屏 0 B，首次见图才下载），预览面板与 HTML 导出不含图 |
| 大纲折叠 | 有；会话内有效，不持久化 |
| 新建、重命名、删除文件 | 有；删除进工作区 `.sidelight/trash/`，可撤销 |
| 快速打开（Ctrl+P） | 有 |
| 最近文件 | 有（8 条，可清除，仅桌面版） |
